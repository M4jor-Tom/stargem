# Spectator Client Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a read-only Bevy spectator at `spectator-client/` that subscribes to a live game over gRPC streaming, plus the minimum server-side wiring (broadcast fan-out + `SpectatorService` + `scenario-runner` binary) so the existing `server/tests/` scenarios become ongoing games the spectator can observe.

**Architecture:** Server's `CombatTickLoop` gains an optional `tokio::sync::broadcast::Sender<GameStateSnapshot>`. A new gRPC `SpectatorService.SubscribeMatch` streams snapshots to clients via `tx.subscribe()`. A `scenario-runner` binary drives the existing test scenarios through a real tick loop while broadcasting. The Bevy spectator-client subscribes via tonic, decodes snapshots into a `LiveWorld` resource, renders ships in 3D (placeholder cube/GLTF), and provides Tab/number-key player-switching plus an egui journal panel.

**Tech Stack:**
- Server: Rust, tonic 0.11, prost 0.12, tokio (existing).
- Spectator-client: Rust, Bevy (latest stable, 0.14+), tonic 0.11, bevy_egui, crossbeam-channel.
- Both: protos at `protos/`, generated via tonic-build.

## Global Constraints

- All server cargo commands run inside the Nix dev shell: `nix develop ./server -c <cmd>`.
- Proto stub regeneration always uses `PROTO_SRC=../protos cargo build` followed by `cargo fmt`.
- Server lives under `server/` (git submodule) — all commits to server code happen with `git -C server commit`. Spectator-client lives under `spectator-client/` and is developed as an in-tree directory in the root repo for now (submodule conversion is a one-line manual step at the end; see Task 15).
- Proto package names already in use: `stargem.grpc.*`, `stargem.quic.*`. The new spectator proto uses `stargem.grpc.spectator`.
- Existing `server/build.rs` only regenerates stubs when `PROTO_SRC` env var is set. Don't change that behavior.
- The three existing tests in `server/tests/ship_destruction_scenario.rs` must keep passing with the same numerical assertions after the scenario refactor.

```rust
use std::collections::HashMap;
use std::pin::Pin;
use std::sync::Arc;

use tokio::sync::{broadcast, Mutex};
use tokio_stream::{wrappers::BroadcastStream, Stream, StreamExt};
use tonic::{Request, Response, Status};
use uuid::Uuid;

use crate::proto_gen::grpc::spectator::{
    spectator_service_server::SpectatorService,
    ListMatchesRequest, ListMatchesResponse, MatchInfo,
    SubscribeRequest,
};
use crate::proto_gen::quic::combat::GameStateSnapshot;
use crate::proto_gen::quic::common::MatchId;

pub struct MatchRegistry {
    matches: HashMap<Uuid, MatchEntry>,
}

struct MatchEntry {
    name: String,
    player_ids: Vec<String>,
    tx: broadcast::Sender<GameStateSnapshot>,
}

impl MatchRegistry {
    pub fn new() -> Self {
        Self { matches: HashMap::new() }
    }

    pub fn register(
        &mut self,
        match_id: Uuid,
        name: String,
        player_ids: Vec<String>,
        tx: broadcast::Sender<GameStateSnapshot>,
    ) {
        self.matches.insert(match_id, MatchEntry { name, player_ids, tx });
    }

    pub fn list(&self) -> Vec<MatchInfo> {
        self.matches.iter().map(|(id, e)| MatchInfo {
            match_id: Some(MatchId { id: id.to_string() }),
            name: e.name.clone(),
            player_ids: e.player_ids.clone(),
        }).collect()
    }

    pub fn subscribe(&self, id: &Uuid) -> Option<broadcast::Receiver<GameStateSnapshot>> {
        self.matches.get(id).map(|e| e.tx.subscribe())
    }
}

pub struct SpectatorHandler {
    pub registry: Arc<Mutex<MatchRegistry>>,
}

type SnapStream = Pin<Box<dyn Stream<Item = Result<GameStateSnapshot, Status>> + Send + 'static>>;

#[tonic::async_trait]
impl SpectatorService for SpectatorHandler {
    type SubscribeMatchStream = SnapStream;

    async fn subscribe_match(
        &self,
        request: Request<SubscribeRequest>,
    ) -> Result<Response<Self::SubscribeMatchStream>, Status> {
        let match_id_str = request.into_inner().match_id
            .ok_or_else(|| Status::invalid_argument("match_id required"))?.id;
        let uuid = Uuid::parse_str(&match_id_str)
            .map_err(|_| Status::invalid_argument("match_id not a uuid"))?;

        let rx = self.registry.lock().await.subscribe(&uuid)
            .ok_or_else(|| Status::not_found("match not registered"))?;

        // BroadcastStream errors (Lagged) are converted into status errors so the
        // client knows it missed frames. ponytail: lagged = drop client, upgrade to
        // resync protocol when a real game generates faster than spectators consume.
        let stream = BroadcastStream::new(rx).map(|r| {
            r.map_err(|e| Status::data_loss(format!("spectator lagged: {e}")))
        });
        Ok(Response::new(Box::pin(stream)))
    }

    async fn list_matches(
        &self,
        _req: Request<ListMatchesRequest>,
    ) -> Result<Response<ListMatchesResponse>, Status> {
        let matches = self.registry.lock().await.list();
        Ok(Response::new(ListMatchesResponse { matches }))
    }
}
```

use stargem_backend::combat::physics::ShipInput;

pub struct Scenario {
    pub name: &'static str,
    pub spawns: Vec<Spawn>,
    pub script: Vec<ScriptStep>,
}

pub struct Spawn {
    pub player_id: Uuid,
    pub position: [f32; 3],
    pub stats: PlayerShipStats,

pub struct ScriptStep {
    pub at_tick: u64,
    pub action: ScenarioAction,
}

pub enum ScenarioAction {
    Input { player: Uuid, input: ShipInput },
    Damage { src: Uuid, tgt: Uuid, dtype: DamageType, raw: f32 },
    EndMatch,
}

pub struct ShipFinal {
    pub shield: f32,
    pub armor: f32,
    pub destroyed: bool,
}

pub struct ScenarioOutcome {
    pub final_ships: HashMap<Uuid, ShipFinal>,
    pub damage_log: Vec<DamageEventRecord>,
}

pub fn run_scenario_sync(scn: &Scenario) -> ScenarioOutcome {
    let mult = DamageMultipliers::default();
    let mut ships: HashMap<Uuid, ShipFinal> = scn.spawns.iter().map(|s| {
        (s.player_id, ShipFinal {
            shield: s.stats.current_shield,
            armor: s.stats.current_armor,
            destroyed: false,
        })
    }).collect();
    let mut log = Vec::new();

    let mut sorted: Vec<&ScriptStep> = scn.script.iter().collect();
    sorted.sort_by_key(|s| s.at_tick);

    for step in sorted {
        match &step.action {
            ScenarioAction::Damage { src, tgt, dtype, raw } => {
                let target = ships.get_mut(tgt).expect("target ship missing");
                if target.destroyed { continue; }
                let r = apply_damage(*dtype, *raw, target.shield, target.armor, &mult);
                target.shield = r.shield_remaining;
                target.armor = r.armor_remaining;
                target.destroyed = r.ship_destroyed;
                log.push(DamageEventRecord {
                    source: src.to_string(),
                    target: tgt.to_string(),
                    damage_type: damage_type_str(*dtype).to_string(),
                    raw_amount: *raw,
                    mitigated_amount: r.mitigated,
                });
            }
            ScenarioAction::Input { .. } | ScenarioAction::EndMatch => {
                // ponytail: sync runner ignores inputs/end. Live runner (Task 7) honors them.
            }
        }
    }

    ScenarioOutcome { final_ships: ships, damage_log: log }
}

use std::sync::Arc;
use std::time::Duration;

use clap::Parser;
use tokio::sync::{broadcast, Mutex};
use tokio::time::interval;
use uuid::Uuid;

use stargem_backend::combat::damage::{apply_damage, DamageMultipliers};
use stargem_backend::combat::physics::PhysicsState;
use stargem_backend::combat::tick::{snapshot_to_proto, DamageEventRecord, PlayerState, TickSnapshot};
use stargem_backend::proto_gen::grpc::spectator::spectator_service_server::SpectatorServiceServer;
use stargem_backend::scenarios::{
    damage_type_str, ship_destruction_electromag, ship_destruction_kinetic,
    ship_destruction_overkill, Scenario, ScenarioAction,
};
use stargem_backend::spectator::{MatchRegistry, SpectatorHandler};

#[derive(Parser, Debug)]
struct Args {
    /// Which scenario to run.
    #[arg(long)]
    scenario: String,

    /// gRPC listen address (spectator subscribers connect here).
    #[arg(long, default_value = "0.0.0.0:50051")]
    grpc_addr: String,

    /// Tick rate (Hz). Lower = slower playback; useful for watching by hand.
    #[arg(long, default_value_t = 2)]
    tick_rate: u64,

    /// Loop the scenario forever so a spectator can join at any time.
    #[arg(long)]
    loop_: bool,
}

fn lookup(name: &str) -> Option<Scenario> {
    match name {
        "ship_destruction_kinetic" => Some(ship_destruction_kinetic()),
        "ship_destruction_electromag" => Some(ship_destruction_electromag()),
        "ship_destruction_overkill" => Some(ship_destruction_overkill()),
        _ => None,
    }
}

#[tokio::main(flavor = "multi_thread", worker_threads = 2)]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    tracing_subscriber::fmt::init();
    let args = Args::parse();
    let scn = lookup(&args.scenario)
        .ok_or_else(|| format!("unknown scenario: {}", args.scenario))?;

    let registry = Arc::new(Mutex::new(MatchRegistry::new()));
    let (tx, _) = broadcast::channel(256);
    let match_id = Uuid::new_v4();
    registry.lock().await.register(
        match_id,
        scn.name.to_string(),
        scn.spawns.iter().map(|s| s.player_id.to_string()).collect(),
        tx.clone(),
    );

    let addr: std::net::SocketAddr = args.grpc_addr.parse()?;
    let svc = SpectatorServiceServer::new(SpectatorHandler { registry: registry.clone() });
    tokio::spawn(async move {
        tonic::transport::Server::builder()
            .add_service(svc)
            .serve(addr).await.unwrap();
    });
    tracing::info!("scenario-runner listening on {}, match_id={}", addr, match_id);

    run_loop(scn, tx, args.tick_rate, args.loop_).await;
    Ok(())
}

async fn run_loop(
    scn: Scenario,
    tx: broadcast::Sender<stargem_backend::proto_gen::quic::combat::GameStateSnapshot>,
    tick_rate: u64,
    do_loop: bool,
) {
    let mult = DamageMultipliers::default();
    let mut interval = interval(Duration::from_secs_f64(1.0 / tick_rate as f64));

    loop {
        // initial ship state from spawns
        let mut ships: std::collections::HashMap<Uuid, PlayerState> = scn.spawns.iter().map(|s| {
            let mut phys = PhysicsState::new();
            phys.position = s.position;
            (s.player_id, PlayerState {
                id: s.player_id.to_string(),
                physics: phys,
                stats: s.stats.clone(),
                shield_hp: s.stats.current_shield,
                armor_hp: s.stats.current_armor,
                energy: s.stats.current_energy,
                heat_level: 0.0,
                input: Default::default(),
            })
        }).collect();

        let mut tick: u64 = 0;
        let mut script_idx = 0;
        let mut sorted: Vec<&_> = scn.script.iter().collect();
        sorted.sort_by_key(|s| s.at_tick);

        let mut ended = false;
        while !ended {
            interval.tick().await;
            tick += 1;

            let mut pending: Vec<DamageEventRecord> = Vec::new();

            while script_idx < sorted.len() && sorted[script_idx].at_tick <= tick {
                let step = sorted[script_idx];
                script_idx += 1;
                match &step.action {
                    ScenarioAction::Damage { src, tgt, dtype, raw } => {
                        if let Some(target) = ships.get_mut(tgt) {
                            let r = apply_damage(*dtype, *raw, target.shield_hp, target.armor_hp, &mult);
                            target.shield_hp = r.shield_remaining;
                            target.armor_hp = r.armor_remaining;
                            pending.push(DamageEventRecord {
                                source: src.to_string(),
                                target: tgt.to_string(),
                                damage_type: damage_type_str(*dtype).to_string(),
                                raw_amount: *raw,
                                mitigated_amount: r.mitigated,
                            });
                        }
                    }
                    ScenarioAction::Input { player, input } => {
                        if let Some(ship) = ships.get_mut(player) {
                            ship.input = input.clone();
                        }
                    }
                    ScenarioAction::EndMatch => { ended = true; }
                }
            }

            let snapshot = TickSnapshot {
                tick_number: tick,
                players: ships.values().cloned().collect(),
                damage_events: pending,
            };
            let _ = tx.send(snapshot_to_proto(&snapshot));
        }

        if !do_loop { break; }
        // Brief pause between loops so spectators see "game over".
        tokio::time::sleep(Duration::from_secs(2)).await;
    }
}

use crossbeam_channel::{bounded, Receiver, Sender};
use tokio::runtime::Runtime;

use crate::proto::common::MatchId;
use crate::proto::combat::GameStateSnapshot;
use crate::proto::spectator::{
    spectator_service_client::SpectatorServiceClient,
    ListMatchesRequest, MatchInfo, SubscribeRequest,
};

#[derive(Debug, Clone)]
pub struct GrpcConfig {
    pub addr: String,
    pub match_name: Option<String>,
    pub match_id: Option<String>,
}

#[derive(Debug)]
pub enum SpectatorEvent {
    Snapshot(GameStateSnapshot),
    Matches(Vec<MatchInfo>),
    Error(String),
}

pub fn spawn_grpc_task(cfg: GrpcConfig) -> Receiver<SpectatorEvent> {
    let (tx, rx) = bounded(1024);
    std::thread::spawn(move || {
        let rt = match Runtime::new() {
            Ok(rt) => rt,
            Err(e) => {
                let _ = tx.send(SpectatorEvent::Error(format!("tokio init failed: {e}")));
                return;
            }
        };
        rt.block_on(run(cfg, tx));
    });
    rx
}

async fn run(cfg: GrpcConfig, tx: Sender<SpectatorEvent>) {
    let endpoint = format!("http://{}", cfg.addr);
    let mut client = match SpectatorServiceClient::connect(endpoint).await {
        Ok(c) => c,
        Err(e) => { let _ = tx.send(SpectatorEvent::Error(format!("connect: {e}"))); return; }
    };

    let matches = match client.list_matches(ListMatchesRequest {}).await {
        Ok(r) => r.into_inner().matches,
        Err(e) => { let _ = tx.send(SpectatorEvent::Error(format!("list: {e}"))); return; }
    };
    let _ = tx.send(SpectatorEvent::Matches(matches.clone()));

    let target_id = match (&cfg.match_id, &cfg.match_name) {
        (Some(id), _) => id.clone(),
        (None, Some(name)) => match matches.iter().find(|m| &m.name == name) {
            Some(m) => m.match_id.as_ref().map(|i| i.id.clone()).unwrap_or_default(),
            None => { let _ = tx.send(SpectatorEvent::Error(format!("no match named {name}"))); return; }
        },
        (None, None) => {
            if matches.len() == 1 {
                matches[0].match_id.as_ref().map(|i| i.id.clone()).unwrap_or_default()
            } else {
                // ponytail: chooser UI deferred; require explicit flag when multiple matches present.
                let _ = tx.send(SpectatorEvent::Error(
                    "multiple matches available; pass --match-name or --match".into()));
                return;
            }
        }
    };

    let mut stream = match client.subscribe_match(SubscribeRequest {
        match_id: Some(MatchId { id: target_id }),
    }).await {
        Ok(r) => r.into_inner(),
        Err(e) => { let _ = tx.send(SpectatorEvent::Error(format!("subscribe: {e}"))); return; }
    };

    loop {
        match stream.message().await {
            Ok(Some(snap)) => { if tx.send(SpectatorEvent::Snapshot(snap)).is_err() { return; } }
            Ok(None) => { let _ = tx.send(SpectatorEvent::Error("stream ended".into())); return; }
            Err(e) => { let _ = tx.send(SpectatorEvent::Error(format!("recv: {e}"))); return; }
        }
    }
}

pub fn switch_target_system(

    let n = world_res.0.players.len();
    if n == 0 { return; }

        world_res.0.follow_idx = (world_res.0.follow_idx + 1) % n;

    ].iter().enumerate() {

            world_res.0.follow_idx = i;
        }
    }
}
